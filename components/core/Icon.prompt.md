Monochrome line icons (24px, 2px stroke) that inherit `currentColor`. The set is the developer's Iconsax-style glyphs recolored white, plus matching UI/social icons.

```jsx
<Icon name="database" size={20} />
<Icon name="cube" duotone />        {/* 0.24 ghost fill */}
<Icon name="github" />
<Icon name="send" />                {/* Telegram */}
<Icon name="arrowUpRight" size={16} />
```

Duotone names (`cube`, `branch`) accept `duotone` for the ghost fill. Names: server, database, terminal, code, shield, bolt, layers, bot, mail, send, github, arrowUpRight, arrowRight, arrowDown, external, check.
